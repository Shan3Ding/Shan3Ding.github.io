# ScholarsArchive

Personal academic website of Shan-Shan Ding, migrated from [Base44](https://shanshanding-fluid.base44.app/) to GitHub Pages.

This is a static copy of the original site: Home, Publications, Curriculum Vitae, Gallery, and News.

## Local preview

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## GitHub Pages

After the repository is on GitHub, the site is published by GitHub Actions. The live URL will be:

`https://<your-github-username>.github.io/scholarsarchive/`
